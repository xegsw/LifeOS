# P3-114 独立产品反例设计（候选阅读前冻结）

## 冻结范围与独立性

- 任务：`LIFEOS-P3-114`，全新隔离、只读独立产品／数据来源／AI 信任与健康安全评审。
- 本设计仅依据任务卡、`ABF-P3-114-v1`、L1/L2 治理、历史冻结边界和关卡定义形成；写入时尚未读取 P3-113 任务卡、ABF、初次／Rework 交付物、专项 Evidence、PM Review 或 PM Evidence。
- 不把 P3-113 执行侧的自检题或 PM 结论作为本设计的主证据。候选阅读后只以独立情境、文本合同逐项对照和结构化结果得出结论。
- 所有反例仅使用固定非敏感虚构人物、虚构工作／健康／健身情境和本地文本／JSON 解析；不运行应用、数据库、模型或网络。

## 预设固定非敏感夹具

- 人物：`林澈`（虚构）；工作语境为“个人作品集发布页更新”，健康／健身语境为“低风险步行与力量训练安排”。
- 四个虚构 Source：用户工作日志、用户训练记录、用户明确同意保存的外部恢复建议摘要、已撤销／过期的外部信息。无真实姓名、健康记录、工作内容、凭据或文件路径。
- 红旗反例只验证产品的停止与转介措辞，不陈述医学诊断或治疗方案。
- 夹具将在唯一 `/private/tmp/lifeos-p3-114-product-review-v1` 中创建，执行后仅精确删除该目录；不扫描、读取或清理其他临时文件。

## 结论口径

- 每项反例仅记为 PASS、FAIL、Unknown 或 N/A（仅 ABF 明示非范围时）。
- P0：主体倒置、来源/身份混淆、健康误导、失败未关闭、历史改写、未经确认的长期影响、越权或虚假冻结／阶段外推。
- P1：首页合同、路线或 Evidence 可复核性存在实质缺口。
- 任何问题必须映射至已有 L1 或 ABF-L2；本设计不新增验收标准。
