- Any Pilot root, retained runtime root, real personal DB, real user directory/file/text, Health data, Person Context, or Memory content.
- Any real Provider endpoint, including DeepSeek, or any network authority, proxy, redirect target, DNS target, or external service.
- Any API key, credential, Keychain item other than a freshly created review-owned synthetic fixture if the candidate profile permits it; no Keychain enumeration is permitted.
- Any P3-139, P3-140, P3-141, or P3-142 candidate/history asset except the exact readonly frozen references bound by the post-seal allowlist procedure.
- Any source, evidence, manifest, review, or runtime root outside the explicit allowlist.

The review will use no shell variable, command-line argument, process environment value, configuration value, or file content as a credential. Any indication of prohibited contact or non-separable secret/content evidence ends this attempt as procedural P0.
