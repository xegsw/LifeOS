# Replay boundary

This attempt cannot be replayed into a valid candidate review. Its purpose is only to preserve the procedure failure and zero-contact boundary.

To begin a replacement attempt, PM must use a different, newly isolated attempt directory and a new reviewer context. Before any candidate-path inventory, metadata query, file read, hash, build, launch, or test, that reviewer must create and hash its self-authored test design and write allowlist, then write a valid precontact seal. Pilot-6 and all prohibited roots remain outside any such preflight.

This attempt has no candidate runner and no automatic rerun command by design.
