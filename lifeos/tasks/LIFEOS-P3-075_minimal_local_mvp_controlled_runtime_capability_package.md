# LIFEOS-P3-075｜最小本地 MVP 受控运行时能力包

## 授权与安全语境

LifeOS 是用户本人拥有并明确授权维护的本地项目。本任务仅针对指定本地工作区、代码和非敏感测试数据，目的是防御性软件工程、代码审查、缺陷修复与本地回归验证。

不涉及外部目标、未授权访问、真实凭据、网络扫描、真实攻击、持久化、数据窃取或安全控制规避。所有权限、失败、恢复与边界术语仅用于验证并修复本项目内部的防御性缺陷，不授权扩大操作范围。所有删除、权限、外部写入和重大行动仍须遵守既有用户确认与安全关卡。

## 状态、角色与模型路由

- 状态：`Ready / Awaiting Explicit Execution Authorization`。用户选择路线 A 仅授权创建本任务，不构成执行授权。
- 主责：新建隔离 Codex 工程会话；不得复用 P3-063 执行或 P3-064 独立评审会话。
- 推荐模型：`gpt-5.6-terra`；推荐推理强度：`high`。
- 选择理由：该包需要在不触达真实路径、文件能力或外部系统的情况下，将既有受控闭环提升为可由操作者本地运行的窄能力，并严守来源、确认与失败语义。
- 允许降级模型：`gpt-5.6-luna` + `high`。
- 禁止降级条件：涉及个人数据、真实用户目录／文件、Tauri/IPC、风险／冻结／基线恢复、Stage 4 或范围冲突时，不得执行，应回报 PM。
- 必须升级条件：发现 P0/P1、Evidence 冲突、越权、真实能力默认关闭失效或需改变已冻结合同，应停止并回报 PM。
- 后备模型：`gpt-5.5` + `xhigh`，仅在记录实际配置与原因后使用。

## 目标

实现并验证一个可由操作者本地运行的最小闭环：**输入一条非敏感本地测试记录 → 明确保存确认 → 保存后才显示成功 → 来源／内容身份可见 → 受控项目上下文恢复 → 操作者确认下一步**。

本任务只验证该受控本地运行时闭环，不宣称真实个人数据、生产耐久、桌面应用、真实导出、真实恢复、真实权限运行链、Alpha 或 Stage 4 能力已具备。

## 数据、环境与目录边界

- 初始数据边界：仅限操作者主动输入的**非敏感测试文本**；不得使用个人日记、客户资料、凭据、真实项目内容或任何需保密的数据。
- 初始环境边界：新建 task-local 隔离目录、SQLite 与系统临时副本；只允许本任务运行时目录内的数据库、日志、快照和测试产物。
- 允许写入：仅 `lifeos/engineering/LIFEOS-P3-075/`、`lifeos/deliverables/LIFEOS-P3-075_minimal_local_mvp_controlled_runtime_capability_package.md` 及其 task-local Evidence。
- 只读输入：P3-063／P3-064、P3-065／P3-066、P3-067／P3-069、P3-072／P3-073、P3-074 授权重跑的交付物／PM Review／Manifest，以及当前状态、R-0019、R-0040、冻结和相关模板。
- 禁止：真实用户目录／路径、真实文件导出、Vault、Obsidian、Tauri/IPC、网络、云／第三方模型、同步、多设备、L3、外部用户、真实 DB migration、Schema/API 修改、工程基线恢复、风险或冻结变更。

## 验收标准

1. 操作者以明确 CLI 或等价本地入口提供非敏感测试文本、幂等键和下一步；不得预置或静默替换输入。
2. 只有本地事务成功提交后才显示成功；空输入、冲突与提交前受控失败必须可见、fail-closed、无半成品且不伪称保存成功。
3. 成功回执必须区分用户原文、来源身份、内容身份、操作者确认、AI 关闭与无外部动作。
4. 同一有效请求幂等；同一幂等键的冲突输入明确拒绝；关闭并重开 task-local SQLite 后已提交记录仍可读。
5. 项目恢复只限受控范围；未知项目明确拒绝；下一步只能由操作者明确确认，且不产生外部动作。
6. 静态检查证明没有真实路径／文件、Tauri/IPC、网络、云、AI 消费、同步、多设备、外部用户或 L3 通道。
7. 不得把本任务写成 R-0019／R-0040 关闭、个人数据许可、生产耐久、真实 MVP Gate 通过、Alpha 或 Stage 4 准入。
