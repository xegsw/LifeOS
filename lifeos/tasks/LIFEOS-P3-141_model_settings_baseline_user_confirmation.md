# LIFEOS-P3-141 模型设置基线用户确认

- 确认时间：2026-08-30
- 生效决策：D-0621
- 用户确认的产品行为：
  - API Key 加密写入 LifeOS 本地数据库，跨重启永久保存，可更新、删除；不提供会话凭据／环境变量产品选项。
  - Cloud Provider 独立显示 OpenAI、Anthropic、DeepSeek、Kimi、自定义 OpenAI-compatible。
  - Local Provider 独立显示 Ollama、LM Studio、自定义本地兼容服务。
  - Cloud／Local 切换时 Provider 集合、配置、状态和模型列表严格分离。
  - 后继任务不得静默删除、合并或回退已确认能力。
- 用户原文：`按照这个更新你的账本，之后不允许出现确定好的内容因为后续任务又改坏的情况`
- 前置确认：`还要把本地和云端选择时 provider 那里的选项区分开`

本确认替代 D-0565～D-0567 中关于会话凭据／环境变量和“密钥已保存只是占位”的错误 PM 转写；历史记录不删除，只撤销其前向产品权威。
