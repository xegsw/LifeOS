## 目标与范围

形成**一个综合、非实施性的准入准备包**，而不是继续拆分微型风险任务：

1. 以已对账的冻结看板与主账本为事实基线，列明有限 Stage 3、未冻结资产、受控范围与 Stage 4 未准入状态。
2. 为五项 Stage 3→4 硬门槛分别定义：最小可验收结果、允许／禁止的 Evidence、责任角色、独立评审要求、停止条件与需要用户确认的节点。
3. 明确 Gate 1–5 在定义层已经可用的输入、尚缺的运行／用户证据，以及不得以合成 SQL 或有限风险关闭替代的部分。
4. 形成单一路线图：先后的依赖关系与最小工作包，但不创建子任务、不选择真实技术实现、不作时间承诺。
5. 明确 R-0040 和其余开放风险对任何真实能力的前置影响，且不建议关闭／重开任何风险。
