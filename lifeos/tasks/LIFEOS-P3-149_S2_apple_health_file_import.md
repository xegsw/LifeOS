## 实施合同

1. 在S2设计文档先固定XML解析、ZIP封装、导入身份、时间/单位映射及有界资源策略。采用流式处理，不把原128KiB/256样本限制当苹果全量导出的能力上限；给出合理可配置技术上限并测试超限诚实失败，不能静默截断。离线缺依赖先报告，不擅自联网。
2. ZIP不是任意解压：拒绝路径穿越、绝对路径、symlink、重复歧义条目、压缩炸弹、损坏/加密包；只处理确定的导出XML，其他附件列为未处理，不访问附件引用或外部URL。XML不得解析外部实体、访问网络或本地文件；苹果常见内联DTD声明可以安全跳过，不盲目拒绝正常导出结构，也不执行实体扩展。
3. 首版结构化映射沿用睡眠、步数、运动时长。使用苹果类型和类别标识，不猜中文“睡眠时间”。其他类型显示数量及“不支持/未导入”，不得声称整个健康库全部支持；不静默抛弃或自动当作医学事实。支持范围是本轮明确限制，扩展指标可另规划。
4. 重复同文件不重复写入；重叠导出不重复计量。无样本UUID时不能把内容指纹冒充稳定样本身份或更正证明；采用批次历史与来源分组，歧义明确不确定。新旧导出缺记录不能推断删除。保留观察时间与导入时间分离，旧数据导入不能刷新为当前状态；可靠同范围替代/跨日/时区规则先说明。必要时保留来源观察但不激活歧义投影，不能为了Pass静默混合旧v1/S1数据。
5. 复用SourcePort/Application/既有Source、State JSON扩展，UI不直连SQL/文件解析。不新增核心实体、表列或放宽固定IPC；如文件选择入口确需新增IPC或关键API，先交PM最小差异，暂停该变化但继续无依赖测试，不擅自更改合同。
