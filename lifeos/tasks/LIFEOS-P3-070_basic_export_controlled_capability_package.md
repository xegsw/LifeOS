# LIFEOS-P3-070｜基础导出受控能力包：合成前置设计与验证

## 授权与安全语境

> LifeOS 为用户本人拥有并授权维护的本地项目。本能力包仅限新隔离目录、只读输入与非敏感合成记录，用于防御性导出边界设计和本地合成验证；不访问真实路径、真实用户数据、凭据、网络或外部目标。真实 DB、文件导出、Vault、Tauri/IPC、云、同步、多设备、L3、外部用户和 Stage 4 均未获授权。

## 能力包

- P0；新隔离 Codex 工程会话；`gpt-5.6-terra` + `xhigh`，不得降级。
- 包边界：仅合成导出计划、范围／来源／身份／确认／冲突／失败语义与关闭态验证；唯一相关风险边界为 R-0040 的前置关闭态。
- 可在同一目录完成实现、回归、必要补测、Evidence 与文案对齐；不得写出真实文件、接入路径或扩大能力。
- 必须定向读取 P3-062、P3-065/P3-066、P3-067/P3-069 Review 与 R-0040；使用任务卡最小启动包。

## 必须验证

1. 合成导出计划须展示来源、内容身份、范围、目标类别、确认、冲突和失败语义；默认不执行。
2. 仅明确 `CONFIRM` 可产生本地“已确认计划”回执，固定为 `external_action=none`，不得创建任意文件或路径写入。
3. 无确认、范围／来源／身份不匹配、冲突、撤回／tombstone 与未知输入均 fail-closed、可审计。
4. 静态和运行检查网络、路径、Tauri/IPC、Vault、真实导出、云、同步、多设备、L3、外部用户均关闭。
5. 生成测试、快照、结构化结果与 Manifest；不修改历史资产或账本。

本包只形成未来真实导出前的受控输入，不满足 R-0040、真实文件导出、风险关闭、冻结或 Stage 4。完成后一次 PM 验收、一次全新隔离独立复评、一次用户采纳；任何跨边界变更须停止并另行授权。
