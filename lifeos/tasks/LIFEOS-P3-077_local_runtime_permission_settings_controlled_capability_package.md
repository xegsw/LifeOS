# LIFEOS-P3-077｜本地受控权限设置运行时能力包

## 授权与安全语境

LifeOS 是用户本人拥有并明确授权维护的本地项目。本任务仅在指定本地工作区、非敏感测试文本、task-local SQLite 与本地临时副本中进行防御性软件工程、权限边界验证、代码审查与回归测试。

不涉及外部目标、未授权访问、真实凭据、网络扫描、真实攻击、持久化、数据窃取或安全控制规避。权限、拒绝、撤回、反例与边界术语只用于验证本项目内部的防御性缺陷，不授权扩大范围。所有删除、权限、外部写入和重大行动仍须遵守既有安全关卡。

## 状态、授权与模型路由

- 状态：`Ready / Task-card Delivery Authorizes Execution`。创建任务不执行；用户将本任务卡路径发送到新建或 PM 指定的 Codex 工程专项会话，即授权在本卡边界内执行。
- 投递前单独确认的例外：None。本任务不得触达真实个人数据、真实 DB／路径／文件、Vault、Tauri/IPC、网络、云／第三方、同步、多设备、L3、外部用户、风险／冻结／基线或 Stage 4。
- 主责：新建隔离 Codex 工程专项会话；不得复用 P3-075 执行会话或 P3-076 独立评审会话。
- 推荐模型：`gpt-5.6-terra`；推荐推理强度：`high`。
- 允许降级模型：`gpt-5.6-luna` + `high`；后备模型：`gpt-5.5` + `xhigh`，须记录原因。
- 禁止降级／必须回报：P0/P1、Evidence 冲突、越权、默认关闭失效、真实能力、风险／冻结／基线／阶段问题或与冻结合同冲突。

## 目标与范围

在新的 task-local 工程目录中实现并验证最小的本地权限设置运行时语义：操作者可查看本次受控处理目的、位置、处理者、有效期和非敏感测试数据边界；通过精确确认作出 grant、deny 或撤回；默认拒绝，当前有效 deny 优先，歧义／过期／撤回全部 fail-closed，并留下 task-local 可追溯审计。

“允许”只能表示 `allowed_local_synthetic`，不读取或外发真实内容，不构成真实 AI、云、第三方、路径、文件或跨设备处理许可。

- 禁止修改 P3-075／P3-076 或任何历史工程、Review、Evidence、账本、风险和冻结文件；禁止真实数据、真实 DB、真实路径／文件、Vault、Tauri/IPC、网络、云／第三方、同步、多设备、L3、外部用户、导出、风险关闭／重开、基线恢复、冻结或 Stage 4。

## 验收标准

1. 默认拒绝；仅唯一、当前有效且精确绑定的 grant 在明确 `CONFIRM` 后可返回 `allowed_local_synthetic`。
2. 当前有效 deny 优先于 grant；歧义 grant、过期、撤回、目的／位置／处理者／数据边界不匹配均拒绝且不产生外部动作。
3. grant、deny、撤回和拒绝都需显示原因、操作者确认与 task-local 审计；不得静默改写用户原文或把拒绝表述为成功。
4. 撤回后此前允许的消费路径必须 fail-closed；重复命令幂等，同一标识的冲突请求可见拒绝。
5. 静态检查没有网络、云、Tauri/IPC、真实路径／文件、AI 消费、导出、Vault、同步、多设备、L3 或外部用户通道。
6. 不得声称真实权限、真实 AI／云处理、R-0013／R-0014／R-0015／R-0021／R-0040 关闭、冻结或 Stage 4。
