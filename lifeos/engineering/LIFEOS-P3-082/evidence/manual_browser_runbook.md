# 本地 `file:` 人工演练步骤

1. 双击或拖入本地浏览器打开 `index.html`；确认默认恢复态、当前 Project、今日安排与“AI 未启用”可见。
2. 点击“暂无可靠建议”，确认没有虚构重点，且只见“选择 Project／先记录当前停点”两条路径；两按钮分别点击一次并记录状态回执。
3. 回到默认恢复态：空文本点击确认，应显示“未保存”；输入一条非敏感合成短文本后点击确认，应显示“你的记录／原文”和“本次页面会话”；点击模拟失败，记录必须隐藏并显示失败。
4. 点击“权限受限 · 离线”，确认本地会话、离线、来源／处理受限和“不生成建议的原因”分别可读，且已确认行动仍可见。
5. 刷新页面；确认第 3 步的合成短文本不再出现。关闭并重新打开后重复确认。
6. 分别在三个状态截屏，记录浏览器、时间、每步 Pass／Fail；不得输入真实个人资料。
