# S2 支持类型与以后真实文件接入

本轮仅合成离线，不要求用户现在导出、上传或选取真实健康文件。手机快捷指令、HealthKit读取、iCloud同步均后置。

| Apple XML类型/类别 | 接收口径 | 明确限制 |
|---|---|---|
| HKQuantityTypeIdentifierStepCount | count，有限非负整数；按来源名称组/offset/日观察 | 重叠区间或同批重复内容不确定，跨日比例分配标估算 |
| HKQuantityTypeIdentifierAppleExerciseTime | min；s换算分钟 | 不等于全部Workout时长；同源重叠不直接相加 |
| HKCategoryTypeIdentifierSleepAnalysis 的 Asleep/AsleepUnspecified/AsleepCore/AsleepDeep/AsleepREM | 必须完整Apple枚举标识；区间裁剪、按日并集 | 只代表导入文件可见睡眠区间，不是Health权威总量 |
| SleepAnalysis InBed/Awake | 保留类别来源观察，不计入睡眠 | 不把卧床等同睡着；不由其推断完整睡眠 |
| 未识别睡眠类别、其他Record类型 | 按类型计不支持，不导入投影 | “睡眠时间”中文不猜映射 |
| Workout、ActivitySummary等其他顶层对象 | 按对象类型计未支持 | 计数单位是顶层对象，不宣称逐个嵌套样本已解析 |
| ZIP其他附件 | 只校验目录安全/容量元数据，计未处理 | 不展开、不读取附件正文、引用或URL；未验证其内容CRC |

正常Apple内联DTD可解析结构而不执行实体；外部DTD、自定义实体声明/引用被拒绝。非法已支持记录、格式损坏、超限导致整批失败，失败1表示一个文件失败，不能得知的记录数量不编造。

界面最近导入时间指文件成功入库时间；同字节文件重传不刷新原导入时间。观察时间来自样本结束日期，过期显示独立；两者不可混同。内容指纹仅用于合成不可变内容去重，未知UUID/修订不能由此恢复。来源名称相同的设备未区分；缺少记录不等于删除。同来源/时间不同值可能是修订也可能是多个样本，保留不确定。

当前合成文件选择器只列S2/inputs内的XML/ZIP，选中一项即导入；不是已实现任意真实文件选择器。真实启用前由PM一次性呈现并明确：用户选择的那个精确文件、允许读取的类型与时间范围、文件整体扫描以筛选类型的边界、专用新库及本地保存位置、正文与摘要/日志披露规则、原文件只读和保存/退出政策。ZIP/XML可能包含本轮不支持的敏感类型，不能把“只投影三项”说成“解析器完全没读到其他类型的属性”。

未来操作形态为用户自己取得Apple健康导出文件，放在一次性授权的专用位置，再在通过该真实合同的App选择文件；当前不指导立即导出或上传。本轮的合成文件hash、目录/DB和程序执行授权不能自动沿用为真实正文处理或真实审计授权。真实文件、iCloud/用户目录、已有个人DB均未探测；无真实安全验收结论。
