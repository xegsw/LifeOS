# P3-144 交互合同

## 边界

- UI 只通过既有 20 项 Tauri IPC 提交严格 DTO；不直连 SQLite、Keychain、网络、SDK、Shell 或文件。
- 只有当前保存的 DeepSeek `https://api.deepseek.com` 配置可显示凭据与逐次激活控件。其余 Cloud／Local Provider 目录保留且明确标记“本轮未验证”。
- API Key 只能在密码输入控件与一次 IPC 调用的有界内存中存在。保存动作先清空控件；界面只回显掩码末四位，不显示前缀或长度。
- 保存、测试并读取模型、选择、启用、发送固定 canary 和删除均为不同的用户操作。保存不会隐式触发后续动作。
- canary 的响应仅当前界面瞬时显示，可显式清除；响应、prompt、Key 与任何个人内容不得进入数据库、日志、截图或 Evidence。

## 可观察流程

| 流程 | 用户操作 | 可观察结果 | 失败关闭 |
|---|---|---|---|
| 配置 | 选择 DeepSeek 并保存 | 端点固定为精确 HTTPS authority；仍未测试 | 非 DeepSeek 没有真实 Gate 控件 |
| 保存凭据 | 在 App 内手工输入并保存 | 输入立即清空；仅显示掩码 | 空值或错误 DTO 不写入 |
| 测试 | 点击“测试并读取模型” | 合成模式无网络；真实 Gate 只请求 DeepSeek 模型目录 | 缺凭据、认证、网络、超时或协议错误均保持禁用 |
| 选择与启用 | 从刚刚测试的目录选择并显式启用 | 启用前不能发送 | 配置或凭据变更撤销模型与启用状态 |
| canary | 点击发送固定无个人含义 canary | 界面瞬时显示，非内容收据可审计 | 未测试、未选模型、未启用或缺凭据均在网络前拒绝 |
| 删除 | 点击删除凭据 | 密文/reference/Keychain 项/运行状态失效 | 后续测试与发送保持拒绝 |

## 可访问性与视觉

- 保留 LifeOS 窄 Icon Rail、弱 Settings 入口、底部 Global AI 空间关系、系统字体、可见焦点和三档响应式 DOM。
- 所有状态同时以文字和色彩表达；原生 button、input、select 保持键盘可操作。
- 除模型设置外的 Settings 分类保持“暂未开放”，不伪装为已实现能力。
