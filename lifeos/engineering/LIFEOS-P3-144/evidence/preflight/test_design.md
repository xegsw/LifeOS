# P3-144 Phase A engineering test design

This engineering-owned design covers only fixed non-sensitive fixtures in the declared synthetic root. It does not substitute for the later independent review design.

1. Recompute the P3-143 source lineage, Cloud 8/Local 4 registry, ordered exact 20 IPC list, and three responsive UI contracts.
2. Exercise Work capture and Health/Fitness Current State separately; reject fourth items, blank items, invalid type/domain, unknown fields, and over-200-character input before writes.
3. Resolve request-scoped context with domain, authorization, validity, recency, relevance, count, character, and token-budget filters. Record opaque item IDs and exclusion reasons only.
4. Require a disclosure preview and a fresh one-time confirmation token before a synthetic DeepSeek adapter response. Attack stale, replayed, changed-selection, canceled, empty-selection, disabled-provider, missing-credential, over-budget, redirect, proxy, retry, and parallel-send paths.
5. Persist model output as Derivation / AI Understanding / Suggestion with source references; exercise confirm, edit, reject, ignore, and correct feedback, then restart and verify invalidated projections.
6. Exercise encrypted credential lifecycle only with synthetic canaries and task-local key material; verify missing and tampered inputs fail before the synthetic network counter changes.
7. Launch an unsigned offline Tauri app from the final candidate for desktop, compact, and narrow target-only native PID → exact-title AXWindow → AXWebArea evidence. If macOS GUI access is unavailable, stop at the affected stage with a checkpoint.
8. Generate a non-self-referential manifest and verifier, then stop writers and perform marker-gated exact cleanup of only the declared synthetic root.

Positive evidence never contains a real user text, a real credential, a real response, or a body hash.
