# LIFEOS-P3-001 最小纵向切片

这是一个仅用于任务验证的本地、确定性、合成数据工程切片。它不是生产应用脚手架，也不冻结 Schema、API、UI、Tauri 配置、导出格式、SLA 或最终目录结构。

## 边界

- Python 标准库与 SQLite/FTS5；无第三方依赖、无网络调用。
- 只读取仓库内 `fixtures/synthetic_v1.json` 合成夹具。
- 真实 Vault、Tauri/IPC、文件导出扩权、云/第三方模型、向量、同步、多设备、L3、外部用户全部没有实现入口且默认关闭。
- 导出是内存中的受控测试包；测试临时数据库只创建在操作系统临时目录。

## 复跑

```bash
cd lifeos/engineering/LIFEOS-P3-001
python3 run_validation.py
```

命令执行原 11 个验收测试组、P3-003 的 5 个回归、P3-005 的 3 个对抗回归及 P3-007 的 4 个根因回归，并重建 `evidence/` 下的机器可读结果、真实断言、内容快照哈希、日志和证据摘要。恢复候选通过进程内引擎边界返回当前 SQLite 权威投影；公开 checksum 只检测未重算损坏，不代表真实性或防伪。该实现仍是合成候选门，不是正式导出 / 恢复协议。成功退出码为 0；任一测试失败退出码非 0。
