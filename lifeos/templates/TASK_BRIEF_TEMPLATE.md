`lifeos/templates/SESSION_REPORT_TEMPLATE.md`

注意：会话回复不要粘贴完整交付物正文，只输出摘要和交付物路径。
注意：不要在聊天中复述任务卡全文、历史背景或大段决策；完整内容写入交付物文件。

## PM 启动说明要求

PM 在给用户可复制提示词前，应简短说明：

- 本任务建议新建会话，还是复用现有会话。
- 建议复用或新建的具体原因。
- 用户应把提示词发到哪类会话。
- 是否需要独立评审会话。
- 专项 Agent 必须重新读取哪些文件。
- 哪些稳定规则文件若未变化、未截断、未压缩且读取状态可靠，可以不重复读取。
- Codex 任务的推荐模型、推荐推理强度、允许降级 / 后备配置，以及禁止降级和必须升级条件；外部 Agent 的 Codex 模型字段写 `N/A`。
