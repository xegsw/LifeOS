更新时间：2026-08-27

本文件用于区分“任务完成”“资产可用”“资产冻结”“允许进入下一阶段”。  
状态变化必须由 PM 主会话更新。

## 状态口径

| 状态 | 含义 |
|---|---|
| Frozen | 已经过必要评审与 PM 确认，成为后续任务必须继承的基线；必须注明冻结范围 |
| Accepted | 任务或计划已验收，可作为后续输入；不自动代表冻结 |
| Accepted but Not Frozen | 资产可用，但仍需独立评审、条件整改、PM 确认或验证 |
| Pass with Conditions | 评审条件通过，条件未完成前不得无条件冻结 |
| Ready | 任务或验证项已由 PM 启动，可交给专项会话执行；不代表已验收或冻结 |
| Rework | 评审未通过，当前资产不能作为冻结候选；需完成指定返工后重新评审 |
| Backlog / Not Started | 已登记但未开始 |
| Blocked / Not Allowed | 当前不允许推进，需满足前置条件 |
