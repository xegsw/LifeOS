# LIFEOS-P2-013｜技术架构冻结条件最终补丁

## 1. 执行摘要

1. **[已验证事实]** P2-010、P2-011 已获 PM 验收和用户采纳；P2-012 独立评审为 `Pass with Conditions`。用户已确认 FTS 维护隔离与 Tauri / IPC 最小安全边界窄测均为技术架构冻结前硬条件。
2. **[结论]** 冻结候选仅包括 V1 技术责任、不变量和默认边界：单设备、本地优先；本地权威原文与控制账本；SQLite + FTS-first；派生可重建、向量后置；权威 / 派生 / outbox 分责；所有消费入口统一重检。
3. **[结论]** Obsidian 仅以默认关闭、只读、条件适配器和降级合同进入候选；同步、服务端栈、真实处理者及实现细节不冻结。

## 3. 技术架构冻结候选范围

1. V1 默认单设备、本地优先；Must 闭环不依赖云端、同步、真实模型或 Obsidian 正式启用。
2. 用户原文及不可变版本、用户确认 / 纠正 / 拒绝 / 撤回、Source / Artifact 与精确版本、Authorization / 政策版本、tombstone / restriction generation、Feedback、最小审计和操作账本是权威事实 / 控制账本；失败不得回执成功，AI、缓存、索引不得覆盖权威。
3. SQLite + FTS-first 是本地检索主路径候选；命中须回连当前权威状态并过滤授权、来源、版本、active、证据和 generation。向量仅在真实授权标注集证明稳定净增益后追加。
4. 分块、索引、摘要、分类、候选、恢复包、缓存及 AI 输出是可重建派生，须绑定精确输入版本、Derivation、内容身份、授权 / 政策版本与 generation；可失效、隔离、删除、重建，失败不影响权威保存。
5. 权威、派生、outbox/job 分责；outbox 与权威变更同事务登记，job 使用幂等键、租约 fencing、重试 / 死信及最小 payload。队列不成为事实来源，死信不解除 active block。
6. 发布、展示、索引、再派生、导出、恢复重建、外发前统一重检版本、授权、Source / 许可、tombstone / restriction generation、证据、目的 / 位置 / 处理者及租约；不匹配即 fail closed。
7. 删除 / 撤回先事务内活跃阻断、推进 generation、失效派生并登记清理任务，再异步物理清理；“已阻断”不冒充“已清除”，旧索引、任务、备份和重连不得复活。
8. “已保存”只代表权威事务耐久提交；索引中、索引失败、清理中、导出失败、恢复中须独立且真实呈现。
9. Obsidian 默认关闭、用户选根、只读、保留外部来源身份，无写 / 删 / 改名；歧义身份候选化、reconciliation 对账、断源不复活。条件不满足时降级为手工导入指定文件、仅来源指针、暂缓接入。
10. 基础导出、数据库感知备份、安全恢复及派生重建保留；模型 / 供应商可替换，真实云、第三方和模型处理者默认关闭。

## 5. FTS 维护隔离窄测合同

**目标与规模。** 关闭 R-0039，证明增量 / 全量维护不以长索引事务阻塞权威捕获且不绕过控制状态。仅用确定性合成数据；建议 10 万内容 / 30 万分块快速回归，100 万内容 / 300 万分块作为与 SP-09 可比的冻结证据主档。规模不足时结论至多 `Pass with Conditions`。

**必测场景与 P0 断言：**

- 增量索引、全量影子或可中断分块重建与持续 / 突发捕获并发；捕获不等待 FTS，耐久提交后才显示已保存。
- 报告捕获 p50 / p95 / p99 / 最大等待；最大等待不得超过已采纳的 1 秒门槛。
- 保存失败注入下误报保存数为 0；未耐久须明确失败。
- 陈旧 posting 必须回连当前权威状态；权限、tombstone、restriction generation 泄漏数均为 0。
- 新索引校验并绑定 generation 后短切换；切换 / 校验失败可回退合法旧索引，无半切换。
- 空间不足、重建中断时不破坏权威库 / 旧索引；捕获继续可用或明确失败；重试幂等，旧任务不覆盖更高 generation。

**证据入口。** 独立 `lifeos/spikes/` 子目录，以 `README.md` 或 `MANIFEST.md` 为入口，列明夹具、环境、命令、机器可读断言、延迟分布、计数、切换 / 回退、空间结果、摘要日志与隐私扫描。

- **Pass：** 全部 P0 通过；最大等待 ≤1 秒；误报保存和三类泄漏均为 0；切换可校验回退；达到主档规模。
- **Pass with Conditions：** 所有 P0 门槛通过，仅主档规模或非目标平台等有限非阻断缺口，且适用范围、关闭能力、补测触发器获 PM 接受。
- **Fail：** 任一 P0 失败，包括超时、误报、泄漏、长事务依赖、不可回退或权威 / 旧索引损坏。

## 6. Tauri / IPC 最小安全边界窄测合同

**目标与证据。** 关闭 R-0040，证明 Renderer 不能绕过后端授权门。须有最小可丢弃 Tauri 集成或等价可执行 harness，包含测试 Renderer、白名单命令、临时允许根 / Vault / 导出目录、边界外目录、symlink 与异常路径；纯说明或截图不足。

**必测场景与 P0 断言：**

- Renderer 无任意文件读写、目录遍历、原始数据库、shell、进程、网络或通用路径命令；未知 IPC 默认拒绝。
- 路径规范化并以真实路径核对允许根；`..`、绝对路径注入、异常编码、NUL、symlink 越界、scope 外 token 默认拒绝。
- `.obsidian`、隐藏 / 排除项、未授权附件拒绝；日志不含正文或真实路径。
- Vault 写命令、删除命令、重命名命令均为 0；通用写命令不可借路径参数写入 Vault。
- 导出仅写用户授权目标；越界、静默覆盖 / 合并、执行导出内容均拒绝，覆盖 / 合并须明确确认。
- IPC 响应保留来源、版本与身份：用户原文、外部来源、AI 派生、AI 推断 / 建议、用户确认，不得降为无来源文本。
- 执行前重检授权、来源、版本、tombstone / restriction generation 与租约；不匹配即 fail closed。

**证据入口。** 独立 `lifeos/spikes/` 子目录及 `README.md` / `MANIFEST.md`，列明最小集成源码、配置、能力 / 命令枚举、测试矩阵、机器可读结果、环境、复现命令和隐私扫描；不得使用真实 Vault。

- **Pass：** P0 全过；越权成功、Vault 写 / 删 / 改名命令、导出越界、身份丢失均为 0。
- **Pass with Conditions：** P0 全过，仅非目标平台 / 打包模式或非 V1 能力缺口；相关能力关闭，条件与补测触发器获 PM 接受。
- **Fail：** 任一 P0 失败或无可执行证据；任意文件权、越界、Vault 写能力、导出越界、默认放行、身份丢失均直接 Fail。

## 7. 两项窄测失败降级与返工路径

| 结果 | 冻结处理与降级 |
|---|---|
| 未执行 / 证据不可复核 | 暂停冻结，修复合同或证据入口后重跑，不得用文档豁免 |
| FTS Fail | 本地搜索架构不冻结；保留权威捕获，禁用在线全量重建，降级为增量、维护窗口、分块或安全旧索引；修复后同规模复测 |
| IPC Fail | Tauri 保持未冻结；关闭失败命令，Obsidian 不启用；导出越界则关闭文件导出；收窄 capability / IPC 后复测，必要时更换桌面壳但继承领域合同 |
| 条件通过 | 仅可请求 PM 接受；条件不得涉及 P0 安全、保存真实性、控制泄漏或回退，须记录范围、关闭能力、失效条件和补测触发器 |
| 两项通过 | 引用证据后可进入冻结决策准备，仍不自动冻结 |

任何降级都不得放宽用户原文保护、授权默认拒绝、AI 身份、重大动作确认、数据主权或 Obsidian 只读底线。
