## 3. 建议冻结范围

建议只冻结以下责任、不变量与默认边界：

1. V1 默认单设备、本地优先；Must 闭环不依赖同步、云端、真实模型或 Obsidian 正式启用。
2. 用户原文、不可变版本、Source / ArtifactVersion、用户确认与 Feedback、Authorization、tombstone / restriction generation、最小审计与操作账本属于本地权威事实 / 控制账本；AI、索引或缓存不得覆盖。
3. SQLite + FTS-first 作为 V1 本地检索主路径；FTS、分块、摘要、分类、候选、缓存与向量属于可失效、可删除、可重建派生，向量后置。
4. 权威事实、可重建派生、outbox / job 职责分离；outbox 与权威变更同事务登记，队列非权威，任务采用幂等、租约 fencing、重试 / 死信，死信不解除活跃阻断。
5. 发布、展示、索引、再派生、导出、恢复、外发前，必须重检当前授权 / 政策、Source / 许可、精确版本、tombstone / restriction generation、证据、目的 / 位置 / 处理者与租约；未知或不匹配即 fail closed。
6. “已保存”只代表权威事务耐久提交。FTS 长维护不得阻塞权威捕获；查询命中须回连当前权威状态，新 generation 校验后才能切换，失败保留合法旧索引。
7. 删除 / 撤回先活跃阻断，再异步物理清理；索引中、索引失败、清理中、导出失败、恢复中等状态必须诚实分离。
8. Obsidian 只冻结默认关闭、用户选根、只读、来源身份、歧义候选化、对账、断源不复活及手工导入 / 来源指针 / 暂缓接入的降级合同，不承诺正式启用。
9. Tauri / IPC 只冻结后端安全合同与复测触发器：Renderer 零通用 OS 能力、IPC 白名单 / 默认拒绝、路径与 scope 校验、Vault 零写、导出隔离与确认、内容身份包络及最小审计。
10. 基础导出、数据库感知备份、安全恢复和派生重建是责任合同；模型与供应商保持可替换。

## 5. R-0039 / R-0040 与条件处置

### R-0039

**[事实]** 可作为已关闭风险进入冻结输入。P2-014 达到 100 万内容 / 300 万分块主档，最大捕获等待 2.952 ms，误报保存与权限、tombstone、restriction generation 泄漏均为 0。冻结的是“FTS 为派生、维护与权威捕获隔离、消费前回连重检、校验后切换”的合同，不是三文件布局、FTS5 或生产 SLA。

### R-0040

**[建议]** 可作为 `Open / Conditional` 被架构合同冻结接受，因为冻结范围只包含经 42/42 PASS 支持的后端安全合同，并明确排除真实 Tauri 配置与能力。该条件不豁免任何 P0 断言。

- **复测触发器：** 首次引入真实 Tauri / Rust 壳；新增或修改 capability、plugin、IPC、路径 scope；启用 Obsidian 或文件导出；debug / release 打包；引入 WebView/CSP、updater、sidecar；增加目标平台或路径库行为变化。
- **关闭能力：** 复测通过前，涉及任意文件、Vault、导出、shell / 进程 / 网络及未验证插件的能力默认关闭；不得处理真实 Vault 或广泛真实文件 scope。
- **失败降级：** 关闭失败命令并收窄 capability / IPC；Vault 边界失败则 Obsidian 保持关闭；导出边界失败则关闭文件导出；修复后复测，必要时更换桌面壳，但不得放宽领域安全合同。
- **风险关闭条件：** 真实目标 Tauri debug / release 与目标平台矩阵迁移通过，P0 失败为 0，并经 PM 验收后，才可建议关闭 R-0040。

### 其他遗留风险

**[推断]** R-0030～R-0038 等开放风险不必阻止本次“合同层冻结”，因为跨平台耐久、依赖完整性、正式导出协议、真实 Vault / 供应商、跨进程租约、生产删除、outbox 原子性和用户状态文案均未被声明为已实现或生产承诺。但它们会阻止对应真实能力启用或 Stage 3 准入，必须在实现切片、真实处理者、真实数据与阶段准入评审中逐项迁移验证；任何用户原文保护、默认拒绝、身份区分、重大动作确认或不复活底线失败，均不得以条件冻结豁免。
