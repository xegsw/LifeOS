## 2. C-01 关闭说明

### 2.1 实际修改

在 `今日 - 权限受限·离线 (LifeOS 精修版)` 中完成两处最小文案校准：

- 将原“已确认：移动端首屏文案应更强调场景感”改为“你已确认 · 决定：移动端首屏文案应更强调场景感。”
- 在“今日安排”标题下新增说明：“仅含你已确认的行动与承诺”。

### 2.2 关闭判断

**[事实]** 独立预览 DOM 中上述两处文字均唯一出现；离线、来源受限、AI 受限与用户决定仍分别表达，且明确暂不生成建议。

**[判断]** 用户确认不再易被理解为系统核验或 AI 判断；“今日安排”明确只容纳用户确认的 `Action / Commitment`。C-01 已关闭。本判断仅覆盖静态表达层。

## 3. C-02 关闭说明

### 3.1 首次取证发现与有限校准

**[事实]** 首次预览时 DOM 已有三条身份与护栏，但 1280×1024 截图仍不能独立核对。

依任务卡“截图暴露证据不完整时可做最小布局 / 文案显性化调整”的授权，执行了以下有限校准：

- 缩短空状态留白并降低最近痕迹图片高度；
- 保留并显性展示三条既有身份：
  - “你的记录 · 原文｜《论自由》第二章阅读笔记”；
  - “个人 Project 入口｜个人网站项目”；
  - “你的记录 · 原文｜上周的生活记录”；
- 将既有护栏句移动到“最近留下的痕迹”标题下方、卡片上方：“仅供你主动打开；尚未选择 Project，不会据此生成恢复或建议。”

未改变“尚未选择 Project”“暂无可靠建议——选择 Project 或补充一条当前停点后再试”“选择 Project”“先记到 Inbox”的状态原因与继续路径。

### 3.2 关闭判断

**[事实]** 最终 JPG 为 1280×1024、无编辑器外壳；标题、未选 Project、无建议原因、三条身份及跨 Project 护栏同图可读；DOM 逐项核对均为唯一命中。

**[判断]** 该截图可脱离 Stitch 编辑器单独用于 PM 核对，并可作为后续 5–10 秒理解测试刺激物。C-02 已关闭。
