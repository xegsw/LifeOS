# SP-08 合成夹具

- 48 条 ArtifactVersion，4 个合成 Project，每个内容单元含 Source、Artifact、Version、Authorization 和最小 AuditEntry。
- 类型轮换覆盖用户原文、Decision、Action、外部材料、AI 派生、AI 候选；另有 47 条 Link、16 条 Feedback，以及对应 Derivation。
- 特殊样例：来源指针、许可内缓存快照、不可再分发外部内容、已删除、处理授权撤回、Source 断开、唯一证据失效、冲突分支、AI 候选、AI 派生、用户确认对象。
- 所有正文均为可公开识别的合成 token；没有真实笔记、真实路径、真实 Vault、附件、凭据、prompt、模型输出或向量。
- 已删除 / 撤回 / 断源 / 证据失效 / 不可导出版本没有正文文件，只在 manifest 中保留身份、状态、generation 与不可还原缺口。

夹具是状态语义测试材料，不是数据库表、正式 Schema、产品对象数量或 UI 信息架构冻结。
